# antika geode mod — Changelog

- **1.9.2** — Force Visibility now works **everywhere**, not just in the editor: with it on, every object the game hides (anything with editor support switched off) is revealed in gameplay too, in every game mode. This release also puts the mod's **source code back on GitHub** — the repository had fallen behind the released binaries, so the code there did not match what you were playing. (Technical note: the reveal runs from the gameplay and editor visibility passes, since the shared base function is inlined and can't be hooked.)
- **1.9.1** — Add Force Visibility: turn it on and every object the editor hides becomes visible and selectable, so nothing in your level stays invisible. Toggle it in the mod settings or from the Eclipse menu.
- **1.9.0** — Add Wave No-Die Block: the Wave mode can't die — spikes touch safely and blocks are passable, exactly like being under a D Block, everywhere. On by default, and toggleable from the mod settings or the Eclipse menu.
- **1.8.6** — Fix the moon launch actually arriving: the Antika Orb now guides you the whole way up (it keeps pushing you upward until you reach the moon's surface), so the trip can't be cut short by anything along the route.
- **1.8.5** — Fix: the camera now follows you during the moon trip, so the moon is actually on screen instead of flying past off-view (GD's normal camera stops at the level's edges, which is far too close for a 9000-unit launch).
- **1.8.4** — Fix: the Antika Orb launches you for real now (it sets your jump velocity instead of teleporting you), so the climb feels like a launch and behaves consistently with the rest of the game.
- **1.8.3** — The Antika Orb now launches you 9000 units up (was 2000).
- **1.8.2** — Find the orbs-tab fix in the editor by the same rule the game itself uses, and log it so the mod can be verified from the log file. Also: old 1.6.7–1.8.0 packages are cleaned out of the install folder so the newest one is the only one Geode loads.
- **1.8.1** — Fix: the Antika Orb and Antika Return Orb now actually show up in the editor's Orbs tab. They're added the way GD itself builds its own tab buttons (through the tab bar's item list), so they appear next to the vanilla orbs just like them — the previous version hooked a different editor function and the buttons could silently fail to appear.
- **1.8.0** — The moon orbs are now a real custom object, and the vanilla orbs are untouched again. Ring, Event Link and the teleport portal are 100% vanilla just as RobTop made them. The new **Antika Orb** (sends you up to the moon) and **Antika Return Orb** (drops you back to where you left) are saved as two invisible, harmless vanilla decorations, so reusing them can't change the look or feel of any existing level — and the mod itself adds both to the editor's Orbs tab, and names them in the info bar. This release also guarantees the old placement crash can never come back: the mod no longer touches or attaches anything to objects while you are editing, so the editor's per-frame sprite batching can't walk into the orb's art again. Note: levels saved with the 1.6.x–1.7.x ring-based orbs now behave like normal rings again — re-place orbs from the new Orbs tab entries.
- **1.7.2** — Fix: the game no longer crashes when you place a moon orb. This was never about sprites: in the editor a GameObject lives inside a sprite batch node, and the editor reorders that batch node every single frame by walking each object's children as if they were all sprites. The orb's drawn art was one of those children, so cocos2d read a sprite out of it and the game went down (this is what has been crashing 1.6.9 and 1.7.0/1.7.1 — the only visible symptom was a crash on placement). Orbs are now drawn in the game only, and nothing at all is attached to an object while you are editing, so placing them is safe. The orbs are recognised by a node tag instead of a node id, which the editor's other mods also leave alone. The Orbs tab entry is still called **Antika Orb** / **Antika Return Orb** in the editor's info bar.
- **1.7.1** — Fix: the game crashed when you placed a moon orb. 1.7.0 was asking GD for orb sprite frames by name to make the orb look like a real orb, and GD crashes when you ask it for a sprite frame that does not exist — so nothing is looked up by name any more. The orb is now drawn entirely on its own: a glowing halo, a bright core, a hard rim and a shine, so it reads as an orb in the game and in the editor's Orbs tab without borrowing anything. The orbs are also no longer tracked by saved pointer, so an orb that gets destroyed mid-level can no longer take the game down with it.
- **1.7.0** — The orbs finally look like orbs, in the editor and in game. The blank icon is gone: the orb is now a real orb sprite out of the game, tinted violet for the way up and cyan for the way back, with a drawn rim and shine over it, and the editor's own entry for it in the Orbs tab shows that same orb, and names it **Antika Orb** / **Antika Return Orb** in the info bar instead of the vanilla object behind it. The moon's ground is a real coloured band now too, so there is always something to stand on. No new image files ship with this, and the orbs still save as the vanilla objects they are built from, so your levels keep working without the mod.
- **1.6.9** — Add the moon: a new placeable orb that throws you 2000 units up to a moon high above the level, and a second orb that drops you back to the exact spot you left from. The moon, its surface, the starfield and both orbs are all drawn by the mod (no new image files), you can run and jump around on the moon's surface, and the screen darkens while you're up there. Works in classic and platformer. Both orbs are vanilla editor objects restyled by the mod: use **Ring** (and the teleport portal built on it) to go up, and **Event Link** to come back, so place the return orb 2000 units above the orb you go up with — and note any existing teleport portal in your levels now sends you to the moon.
- **1.6.8** — Fix: the forced game modes (All Modes in Platformer and Force Game Mode) no longer lose to the level's portals — the chosen mode is re-applied every frame, so ship/ball/UFO/wave/robot/spider/swing portals in the level can't switch you out of it. Picking Cube now also forces you back to the cube when a portal tries to change your mode.
- **1.6.7** — Add Don't Move Camera: the camera stays on the level's starting view instead of following the player, so it never pans, zooms or reacts to the level's camera triggers. Also add Force Game Mode: play classic levels as Ship, Ball, UFO, Wave, Robot, Spider or Swing (pick it in the mod settings) instead of only Cube, mirroring All Modes in Platformer.
- **1.6.6** — Add Force Classic: play platformer levels in classic mode (it wins over Force Platformer when both are on). Force Platformer and Force Classic are now re-applied after dying and respawning, which also makes Force Platformer survive a respawn in classic levels.
- **1.6.5** — Add a keybind that replays the story ending dialog at any time: press **Ctrl+Shift+K** (works everywhere, and can be rebound in Geode's keybind settings; press it again to close the dialog). Also fixes the main menu: the mod was replacing `MenuLayer::update` without calling the original, so the menu's own update logic never ran.
- **1.6.4** — Combined release: the single .geode package now ships every platform together (Windows `rolikakiu.multimode.dll`, Android 32-bit `rolikakiu.multimode.android32.so`, Android 64-bit `rolikakiu.multimode.android64.so`), so one download installs on all of them. No gameplay or bugfix changes since 1.6.3.
- **1.6.3** — Add Android support: the mod now builds and runs on Android (2.2081) as well as Windows. Also: renamed the misleading "Disable" setting to "Story Mode", declared an incompatibility with other Negative Hitboxes mods, gave the mod's nodes prefixed IDs, and fixed the Accurate Hitboxes debug overlay not lining up with the real hitbox on rotated spikes.
- **1.6.2** — Fix: the Make Everything 3D effect now stays on when you die and respawn instead of turning off.
- **1.6.1** — Re-upload: hosted on the dedicated Antika-Geode-Mod repository.
- **1.6.0** — Add All Modes in Platformer: play platformer levels as Ship, Ball, UFO, Wave, Robot, Spider or Swing (pick it in the mod settings) instead of only Cube.
- **1.5.0** — Add Noclip (spikes notouch, blocks passable, no deaths), Force Ice (every block is ice in platformer), and Force Platformer (classic levels in platformer mode).
- **1.4.0** — Add Eclipse integration: an "antika" tab with toggles for all settings (Story, Negative Hitboxes, Negative, Accurate Hitboxes, TRUE Hitboxes) synced to Eclipse config.
- **1.3.0** — Add Accurate Hitboxes (accurate spike/saw shapes, kills + debug draw) and TRUE Hitboxes (every hazard gets an accurate hitbox; requires Accurate Hitboxes).
- **1.2.0** — Rewrite Negative Hitboxes to use the real technique: negate every object's scale (-1) and turn off the level's "Fix Negative Scale". Removed Safe-Mode setting.
- **1.1.0** — Add Negative Hitboxes (hazards safe, die in empty space), Negative (upside-down world flip, inverted landing, photo-negative filter; only enable-able with Negative Hitboxes), and Safe-Mode settings.
- **1.0.3** — Rename setting to "disable": when enabled, play level 149188646 and show the ending dialog after beating it.
- **1.0.2** — Fix popup not showing when "end" is enabled.
- **1.0.1** — Fix "end": close the popup when leaving the main menu.
- **1.0.0** — Release.
